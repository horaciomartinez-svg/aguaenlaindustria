# Foro Estatal Agua en la Industria — Tamaulipas 2026

Portal web oficial del Foro Estatal "Agua en la Industria", organizado por la Secretaría de Recursos Hidráulicos para el Desarrollo Social del Gobierno del Estado de Tamaulipas.

- **Fecha:** 24 y 25 de septiembre de 2026
- **Sede:** Centro de Convenciones "Mundo Nuevo", Matamoros, Tamaulipas
- **Dominio:** www.aguaenlaindustria.lat

## Estructura

```
index.html          Página principal (sitio de una sola página)
css/styles.css      Estilos (paleta institucional guinda/dorado)
js/main.js          Menú móvil, cuenta regresiva, animaciones
assets/             Logotipos (logo-foro.jpg, logo-srhds.png)
```

Sitio estático sin dependencias de build: apto para Cloudflare Pages (deploy directo desde este repositorio, sin comando de compilación).
